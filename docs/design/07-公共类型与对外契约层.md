| code | info |

#### 12.1.3 `BaseEvent<T>`

```java
public abstract class BaseEvent<T> {
    public abstract EventMessage<T> buildEventMessage(T data);
    public abstract String exchange();     // 空串 = 默认交换机
    public abstract String routingKey();   // 默认交换机下 = 队列名
    public abstract String queue();

    @Data @Builder @AllArgsConstructor @NoArgsConstructor
    public static class EventMessage<T> {
        private String id;          // 消息唯一 ID（消费侧幂等键）
        private Date timestamp;     // 事件生成时间
        private T data;             // 业务数据
    }
}
```

#### 12.1.4 `AppException`

继承 `RuntimeException`，字段 `code / info`；4 个构造方法（仅 code / code + cause / code + message / code + message + cause）。

### 12.2 `marketing-api` 对外契约层

#### 12.2.1 Service 接口

**`IRaffleActivityService`**（`@RequestMapping("/api/${app.config.api-version}/raffle/activity/")`）：

| 方法 | HTTP | 路径 | 入参 | 返回 |
|---|---|---|---|---|
| `armory(Long activityId)` | GET | `/armory` | 路径/查询参数 | `Response<Boolean>` |
| `draw(ActivityDrawRequestDTO)` | POST | `/draw` | `{userId, activityId}` | `Response<ActivityDrawResponseDTO>` |
| `calendarSignRebate(String userId)` | POST | `/calendar_sign_rebate` | form `userId` | `Response<Boolean>` |
| `isCalendarSignRebate(String userId)` | POST | `/is_calendar_sign_rebate` | form `userId` | `Response<Boolean>` |
| `queryUserActivityAccount(UserActivityAccountRequestDTO)` | POST | `/query_user_activity_account` | `{userId, activityId}` | `Response<UserActivityAccountResponseDTO>` |

| 方法 | HTTP | 路径 | 入参 | 返回 |
|---|---|---|---|---|

#### 12.2.3 `Response<T>`

```java
@Data @Builder @AllArgsConstructor @NoArgsConstructor
public class Response<T> implements Serializable {
    private String code;   // ResponseCode.code
    private String info;   // ResponseCode.info
    private T data;        // 业务数据（泛型）
}
```

使用方式：`Response.<T>builder().code("0000").info("成功").data(...).build()`
