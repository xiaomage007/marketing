### 13.4 Repository 实现（6 个）

#### 13.4.1 `ActivityRepository`

```java
@Slf4j @Repository
public class ActivityRepository implements IActivityRepository {
    @Resource private IRedisService redisService;
    @Resource private IRaffleActivityDao raffleActivityDao;
    @Resource private IRaffleActivitySkuDao raffleActivitySkuDao;
    @Resource private IRaffleActivityCountDao raffleActivityCountDao;
    @Resource private IRaffleActivityOrderDao raffleActivityOrderDao;
    @Resource private IRaffleActivityAccountDao raffleActivityAccountDao;
    @Resource private IRaffleActivityAccountMonthDao raffleActivityAccountMonthDao;
    @Resource private IRaffleActivityAccountDayDao raffleActivityAccountDayDao;
    @Resource private IUserRaffleOrderDao userRaffleOrderDao;
    @Resource private TransactionTemplate transactionTemplate;
    @Resource private IDBRouterStrategy dbRouter;
    @Resource private ActivitySkuStockZeroMessageEvent activitySkuStockZeroMessageEvent;
    @Resource private EventPublisher eventPublisher;
}
```

**关键方法特性**：

| 方法 | 关键实现 |
|---|---|
| `doSaveCreditPayOrder(agg)` | `dbRouter.doRouter(userId)` + `transactionTemplate.execute`；只写订单（state=wait_pay），不动账户；`DuplicateKeyException → AppException(INDEX_DUP)` |
| `doSaveNoPayOrder(agg)` | **分布式锁** `ACTIVITY_ACCOUNT_LOCK + userId + "_" + activityId`（3 秒）+ 同上事务；订单（completed, payAmount=0）+ 三账户累加 |
| `updateOrder(DeliveryOrderEntity)`（第 27 节新增） | **分布式锁** `ACTIVITY_ACCOUNT_UPDATE_LOCK + userId`（3 秒）→ `queryRaffleActivityOrder(userId + outBusinessNo)` 查订单 → 事务内 `updateOrderCompleted`（`WHERE state='wait_pay'` 条件更新，影响 0 行 → rollback 幂等）→ 总账户 query 后 insert/updateAccountQuota + 月/日账户 addAccountQuota |
| `subtractionActivitySkuStock(sku, cacheKey, endDateTime)` | DECR + SETNX 分段锁；surplus==0 时 `eventPublisher.publish(activitySkuStockZeroMessageEvent, sku)` |
| `saveCreatePartakeOrderAggregate(agg)` | 单事务 update 三账户 + insert 抽奖单；影响 0 行抛 `ACCOUNT_QUOTA_ERROR` / `_MONTH_` / `_DAY_` |
| `queryActivityAccountEntity(activityId, userId)` | 三张账户表联合；日/月账户缺失时回退总账户镜像 |

#### 13.5.2 `RedissonService`

`@Service("redissonService")` + `@Resource RedissonClient redissonClient`：**薄封装**，每方法直接转发到 `redissonClient`，无业务逻辑。注释中明确「key 不做前缀拼接，调用方自行保证 key 全局唯一」。

> 抽奖专用方法（`atomicDecr / getRateRange` 等）**不存在**，所有抽奖逻辑由 `StrategyRepository` 通过通用 `decr / setValue / getMap` 组合实现。

### 13.6 MQ 三件套

#### 13.6.1 `EventPublisher`

```java
@Slf4j @Component
public class EventPublisher {
    @Autowired private RabbitTemplate rabbitTemplate;

    public <T> void publish(BaseEvent<T> event, T data) {
        publish(event.exchange(), event.routingKey(), event.buildEventMessage(data));
    }
    public void publish(String exchange, BaseEvent.EventMessage<?> eventMessage) {
        publish(exchange, "", eventMessage);
    }
    public void publish(String exchange, String routingKey, BaseEvent.EventMessage<?> eventMessage) {
        publish(exchange, routingKey, JSON.toJSONString(eventMessage));
    }
    public void publish(String exchange, String routingKey, String messageJson) {
        rabbitTemplate.convertAndSend(exchange, routingKey, messageJson);
    }
}
```

所有方法均有 try-catch，失败 `log.error` 后 `throw e`（让上游感知；trigger 层与仓储层会决定是否再封装一层）。

#### 13.6.2 `RabbitMqTopologyProperties`

`@ConfigurationProperties(prefix = "rabbitmq.topology")`，3 个 Map：

```yaml
rabbitmq:
  topology:
    exchanges: { send_award: { type: direct, name: send_award, durable: true }, ... }
    queues:    { send_award: { name: send_award, durable: true }, credit_adjust_success: { name: credit_adjust_success, durable: true }, ... }
    bindings:  { send_award_bind: { destinationType: queue, source: send_award, destination: send_award }, ... }
```

内部类：`ExchangeProperties{type, name, routingKey, durable, autoDelete, arguments}` / `QueueProperties{name, durable, exclusive, autoDelete, arguments}` / `BindingProperties{destinationType, source, destination, routingKey, arguments}`。

#### 13.6.3 `RabbitMqConfig`

`@Configuration @EnableConfigurationProperties(RabbitMqTopologyProperties.class)`：

```java
@Bean
public Declarables rabbitTopologyDeclarables(RabbitMqTopologyProperties props) {
    // 1. 遍历 exchanges → buildExchange → DirectExchange/FanoutExchange/TopicExchange/HeadersExchange
    // 2. 遍历 queues    → new Queue(...)
    // 3. 遍历 bindings  → buildBinding（routingKey 省略时继承 source 的默认路由键）
    // 4. 返回 Declarables（由 RabbitAdmin 启动时自动 declare）
}
```
