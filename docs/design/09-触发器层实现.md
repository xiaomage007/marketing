## 十四、触发器层实现

### 14.1 包结构

```
com.charlie.trigger/
  ├─ http/        2 个 Controller（@RestController）
  ├─ job/         3 个 Job（@Component + @Scheduled）
  └─ listener/    5 个 Listener（@Component + @RabbitListener）
```

### 14.2 Controller（2 个）

#### 14.2.1 `RaffleActivityController`

`@RequestMapping("/api/${app.config.api-version}/raffle/activity/") implements IRaffleActivityService`

依赖：`IRaffleActivityPartakeService / IRaffleActivityAccountQuotaService / IRaffleStrategy / IAwardService / IActivityArmory / IStrategyArmory / IBehaviorRebateService`

| 端点 | 串联服务 |
|---|---|
| `GET /armory?activityId=` | `activityArmory.assembleActivitySkuByActivityId` → `strategyArmory.assembleLotteryStrategyByActivityId` |
| `POST /draw` | 参数校验 → `raffleActivityPartakeService.createOrder` → `raffleStrategy.performRaffle` → `awardService.saveUserAwardRecord` |
| `POST /calendar_sign_rebate?userId=` | 构造 `BehaviorEntity(type=SIGN, outBusinessNo=当天 yyyyMMdd)` → `behaviorRebateService.createOrder` |
| `POST /is_calendar_sign_rebate?userId=` | `behaviorRebateService.queryOrderByOutBusinessNo` |
| `POST /query_user_activity_account` | `raffleActivityAccountQuotaService.queryActivityAccountEntity` |

**异常处理**：`AppException` 透传 code/info，其它异常返回 `UN_ERROR`。

#### 14.2.2 `RaffleStrategyController`

`@RequestMapping("/api/${app.config.api-version}/raffle/") implements IRaffleStrategyService`

依赖：`IRaffleAward / IRaffleStrategy / IStrategyArmory / IRaffleRule / IRaffleActivityAccountQuotaService`

| 端点 | 串联服务 |
|---|---|
| `GET /strategy_armory?strategyId=` | `strategyArmory.assembleLotteryStrategy` |
| `POST /query_raffle_award_list` | `raffleAward.queryRaffleStrategyAwardListByActivityId` + `raffleRule.queryAwardRuleLockCount` + `raffleActivityAccountQuotaService.queryRaffleActivityAccountDayPartakeCount` |
| `POST /query_raffle_strategy_rule_weight` | `raffleActivityAccountQuotaService.queryRaffleActivityAccountPartakeCount` + `raffleRule.queryAwardRuleWeightByActivityId` |
| `POST /random_raffle` | `RaffleFactorEntity(userId="system", strategyId)` → `raffleStrategy.performRaffle` |

### 14.3 Job（3 个，cron `0/5 * * * * ?`）

| Job | 职责 |
|---|---|
| `UpdateAwardStockJob` | `raffleStock.takeQueueValue()` 非阻塞 poll → `raffleStock.updateStrategyAwardStock(strategyId, awardId)` 落库 |
| `UpdateActivitySkuStockJob` | `skuStock.takeQueueValue()` → `skuStock.updateActivitySkuStock(sku)` |
| `SendMessageTaskJob` | `dbRouter.dbCount()` 个库并行 → 每库 `dbRouter.setDBKey(dbIdx)` 路由 → `taskService.queryNoSendMessageTaskList` → 线程池并行 `sendMessage` → 成功置 completed / 失败置 fail；finally 必 `dbRouter.clear()` |

所有 Job 方法体外层 try-catch，保证 `@Scheduled` 不中断。

### 14.4 Listener（5 个）

| Listener | 监听队列（SpEL） | 消息体 | 处理 service |
|---|---|---|---|
| `ActivitySkuStockZeroCustomer` | `#{@rabbitMqTopologyProperties.queues['activity_sku_stock_zero'].name}` | `EventMessage<Long>(data=sku)` | `skuStock.clearActivitySkuStock(sku)`（DB 置 0） |
| `SendAwardCustomer` | `queues['send_award'].name` | `EventMessage<SendAwardMessage>` | 构造 `DistributeAwardEntity{userId, orderId, awardId, awardConfig}` → `awardService.distributeAward` |
| `RebateMessageCustomer` | `queues['send_rebate'].name`（已对齐 §八 Q8） | `EventMessage<RebateMessage>` | sku → `SkuRechargeEntity` → `activityQuotaService.createOrder`；integral → `TradeEntity` → `creditAdjustService.createOrder` |
| `CreditAdjustSuccessCustomer`（第 27 节新增） | `queues['credit_adjust_success'].name` | `EventMessage<CreditAdjustSuccessMessage>` | 构造 `DeliveryOrderEntity{userId, outBusinessNo}` → `activityQuotaService.updateOrder` |

**异常处理统一约定**：`AppException(INDEX_DUP)` → log warn + return（幂等兜底）；其它异常 rethrow → 本地重试 3 次 → 死信。

> `SendAwardCustomer` 当前源码 catch 后**未 rethrow**（注释 `throw e;` 被注释掉），失败可能被静默吞掉；如需严格 at-least-once 应恢复 rethrow（已在 §八 Q4 历史修复记录中说明早期实现演进）。
