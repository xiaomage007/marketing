## 十五、扩展指南（补充）

### 15.1 新增发奖实现

1. 在 `marketing-domain/.../award/service/distribute/impl/` 新建 `XxxAward implements IDistributeAward`；
2. 类上 `@Component("award_key")`（**bean 名 = `award.award_key`**）；
3. `giveOutPrizes(DistributeAwardEntity)`：优先 `entity.getAwardConfig()`，未传时 `awardRepository.queryAwardConfig(awardId)` 兜底；
4. 入账遵循「先 UPDATE 影响 0 行 → INSERT」+ `WHERE state='create'` 条件 UPDATE 的幂等栅栏；
5. 在 `award` 表新增对应行，无需重启（Spring 启动时自动扫入 `distributeAwardMap`）。

### 15.2 新增积分交易类型

1. 在 `TradeNameVO` / `TradeTypeVO` 追加枚举值；
2. 在 `CreditRepository` 中补对应业务逻辑（账户 update + 流水 insert + task insert）；
3. 消费侧如需新触发场景，在 `trigger/` 下新增 `@RabbitListener` 或 `@RestController` 入口调用 `creditAdjustService.createOrder`。

### 15.3 新增行为类型

1. 在 `BehaviorTypeVO` 追加枚举值；
2. 在 `daily_behavior_rebate` 表新增配置（`behavior_type + rebate_type + rebate_config`）；
3. 入口可在 `RaffleActivityController` 暴露新接口，或由外部事件经 MQ 触发。

### 15.4 新增交易策略（第 27 节）

`activity` 域额度下单的交易动作由 `ITradePolicy` 策略族承担（`activity/service/quota/policy/`），新增一种交易方式：

1. 新建 `XxxTradePolicy implements ITradePolicy`，类上标注 `@Service("xxx_trade")`（**bean 名 = `OrderTradeTypeVO.code`**）；
2. `trade(CreateQuotaOrderAggregate)` 内设置订单状态（`agg.setOrderState(...)`，必要时设置 `payAmount`）并调用 `IActivityRepository` 对应落库方法（落库方法需先在 domain 接口声明、infrastructure 实现）；
3. 在 `OrderTradeTypeVO` 追加枚举项（code 与 bean 名一致）；
4. 调用方传 `SkuRechargeEntity.orderTradeType` 即可路由到新策略——`AbstractRaffleActivityAccountQuota` 构造函数注入 `Map<String, ITradePolicy>` 自动收集，无需改服务层代码。
