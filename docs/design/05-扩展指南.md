## 九、扩展指南

### 9.1 新增抽奖前置规则（责任链节点）

1. `rule/chain/impl/` 新建 `RuleXxxLogicChain extends AbstractLogicChain`，类上 `@Component("rule_xxx")`；
2. 实现 `logic(userId, strategyId)`（接管返回 `StrategyAwardVO`，放行 `next().logic(...)`）与 `ruleModel()`；
3. 数据库 `strategy.rule_models` 加 `rule_xxx` 即生效（无需改工厂）。

### 9.2 新增抽奖后置规则（决策树节点）

1. `rule/tree/impl/` 新建 `RuleXxxLogicTreeNode implements ILogicTreeNode`，`@Component("rule_xxx")`；
2. 实现 `logic(userId, strategyId, awardId, ruleValue)`；
3. 在 `rule_tree_node` / `rule_tree_node_line` 配置节点与出边（或新建一棵树挂到 `strategy_award.rule_models`）。

### 9.3 新增 MQ 队列

1. `application-*.yml` 的 `rabbitmq.topology.queues` 增加逻辑 key（需要交换机时补 exchanges/bindings 段）；
2. 领域层定义 `BaseEvent` 子类事件（exchange/routingKey/queue + 消息体）；
3. 发送方走 `EventPublisher`；消费方 `@RabbitListener(queues = "#{@rabbitMqTopologyProperties.queues['逻辑key'].name}")`。

### 9.4 新增定时任务

`trigger/job/` 新建 `@Component` + `@Scheduled(cron=...)`，整方法体 try-catch 包裹（防调度中断），领域依赖通过 `IRaffleStock` / `IRaffleActivitySkuStockService` / `ITaskService` 等领域接口注入。

### 9.5 新增发奖策略实现（第 25 节）

1. 在 `marketing-domain/.../award/service/distribute/impl/` 新建 `XxxAward implements IDistributeAward`；
2. 类上标注 `@Component("award_key")`（**bean 名 = `award.award_key`**，是发奖路由的唯一 key）；
3. 实现 `giveOutPrizes(DistributeAwardEntity)`：优先取 `entity.getAwardConfig()`，未传时 `awardRepository.queryAwardConfig(awardId)` 兜底；
4. 入账涉及账户表时，沿用「先 UPDATE WHERE user_id 影响 0 行 → INSERT」的免查开户模式，配合状态字段的 `WHERE state='create'` 条件 UPDATE 形成幂等栅栏；
5. `award` 表新增对应行后无需重启服务（新 bean 会被 Spring 自动扫描并入 `distributeAwardMap`）。
